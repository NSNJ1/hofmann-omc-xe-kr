# Data and code availability statement

The following version-specific statement may be used in the manuscript:

> The numerical source data, representative VASP input structures, selected
> VASP text outputs, occupation-matrix tables, reduced charge-density data,
> and post-processing and figure-generation scripts supporting this study are
> openly available in the GitHub repository at
> https://github.com/NSNJ1/hofmann-omc-xe-kr and archived in Zenodo under DOI
> 10.5281/zenodo.24377761 (version 1.1.0). VASP `POTCAR` datasets, compiled
> VASP/OMC executables, `WAVECAR` files, and full `CHGCAR` volumes are not
> redistributed because of licensing and size constraints; the reduced
> density slices used for the plotted charge-density analysis are included.
