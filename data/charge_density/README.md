# ZJU74 Δρ 数据包（2026-10-18，本机 numpy 计算）

## 约定

- CHGCAR 数值 = ρ×V；ρ = 数值/V；Δρ = 前 − 后。
- 气体差分：Δρ = ρ(复合物) − ρ(去客体) − ρ(气体)；网格 120³，胞 7.4027×7.4027×7.1261 Å。
- 气体盒能量为正（单原子小盒旧设置）——只作密度参考，不参与能量账。
- **金属差分注意**：Ni 复合物用 Ni_pv（16 价电子，含 3p 半芯），Pd/Pt 为 10 价电子；因此 metal_ni 的 ∫Δρ = +6 e，属价电子数差异而非键合。metal_ni 切片已掩掉 r<0.8 Å 核区；金属差异的定量请用 metal_pt（∫Δρ=0）与 T3 电荷表/d 带 DOS。
- **sub_on_gas**：Δ(气体诱导重排)=（CH3 复合物−CH3 去客体）−（H 复合物−H 去客体），专看甲基如何改变客体周围的电子重排；∫Δρ 应≈0。
